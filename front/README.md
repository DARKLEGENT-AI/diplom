# МедУчет Frontend

Frontend для веб-системы учета медицинского учреждения. Интерфейс разделяет сценарии пациента и врача.

## Стек

- React
- TypeScript
- Vite
- React Router
- Axios
- Tailwind CSS

## Запуск

```bash
npm install
npm run dev
```

Production-сборка:

```bash
npm run build
npm run preview
```

## Переменные окружения

Файл `.env`:

```env
VITE_API_URL=http://localhost:4000/v1
```

## Основные экраны

- Вход, регистрация и восстановление пароля.
- Пациентская запись к врачу: выбор врача, дня и свободного времени.
- Блок `Мои записи` для пациента.
- Кабинет врача с таблицей расписания.
- Личный кабинет с городом, аватаром и профилем врача.
- FAQ с разными вопросами для пациента и врача.
- Поддержка с чатом и формой обращения.

## Роли

- `patient` — записывается к врачу и видит свои приемы.
- `doctor` — управляет расписанием и профилем специалиста.
- `admin` — получает доступ к отчетам и служебным разделам.

## UI

- Светлая и темная тема.
- Красный медицинский акцент.
- Квадратная аватарка пользователя.
